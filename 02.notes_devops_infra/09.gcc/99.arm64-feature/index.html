    ACLE (Arm C Language Extensions) 支持#

    GCC 14 ACLE 新增#

    • Function Multiversioning Specification (Beta)
    • Memory prefetch intrinsics
    • Special register intrinsics (128-bit extension +d128)
    • NEON-SVE Bridge intrinsics (arm_neon_sve_bridge.h)
    • 更多 intrinsics 无需指定更高架构级别

    GCC 15 ACLE 新增#

    • Guarded control stacks intrinsics
    • Lookup table intrinsics (__ARM_FEATURE_LUT)
    • FAMINMAX intrinsics (__ARM_FEATURE_FAMINMAX)
    • FP8 系列 intrinsics (__ARM_FEATURE_FP8*)
    • SVE2.1 intrinsics (__ARM_FEATURE_SVE2p1)
    • SME2.1 intrinsics (__ARM_FEATURE_SME2p1)
    • SVE/SME BFloat16 intrinsics
    • SVE vector operators (__ARM_FEATURE_SVE_VECTOR_OPERATORS==2)
    • __fma / __fmaf intrinsics
    • __chkfeat intrinsic

    GCC 16 ACLE 新增#

    • __sqrt / __sqrtf intrinsics
    • __atomic_store_with_stshh intrinsic
    • __pldir intrinsic
    • Build attributes 支持 (__ARM_BUILDATTR64_FV)
    • Function Multi Versioning 正式支持 (__HAVE_FUNCTION_MULTI_VERSIONING)
    • SME2 FP8 conversions intrinsics
    • SVE floating-point matrix multiply intrinsics
    • FP8 multiply-add long intrinsics
    • SVE/SME LUTv2 intrinsics
    • Packed boolean vectors (C/C++ SVE booleans)

    优化改进#

    GCC 14 优化#

    • AArch64 特定寄存器分配优化 (-mearly-ra=)
    • Load/store-pair 指令融合优化 (-mearly-ldp-fusion, -mlate-ldp-fusion)
    • 自动使用 strided vector register operands (SME)
    • 减少 Advanced SIMD 和 SVE 代码中的冗余移动

    GCC 15 优化#

    • 自动使用 AArch64 CRC 指令
    • 自动使用 saturating vector arithmetic 指令
    • 改进 population count 代码生成
    • 改进浮点和 vector immediates 处理
    • 改进 vector permutations 处理
    • 更多 SVE 指令优化 Advanced SIMD 代码
    • SVE ACLE intrinsics folding 和 simplification
    • 改进 CPU-specific tuning
    • 改进寄存器分配（消除 vector moves）
    • 128-bit atomic operations 扩展支持 LRCPC3

    GCC 16 优化#

    • 自动向量化 ISA 选择 (-mautovec-preference)
    • MTE stack tagging (-fsanitize=memtag)
    • ARM SPE profiler 支持
    • 64-bit x-register 转 32-bit w-register 优化（针对特定 CPU）
    • C++ spaceship operator (<=>) 优化
    • preserve_none 调用约定支持
    • Build attributes 用于标记 GCS 代码

    重要变更说明#

    弃用和移除#

    版本 弃用/移除内容
    GCC 14 Xeon Phi (Knight Landing/Mill) CPU 支持 - 将在 GCC 15 移除
    GCC 15 ILP32 (-mabi=ilp32) 支持弃用 - 将在未来版本移除
    GCC 15 Xeon Phi CPU 支持移除
    GCC 16 PC relative literal loads (-mpc-relative-literal-loads) 弃用

    新增目标支持#

    版本 新目标
    GCC 15 AArch64 MinGW (aarch64-w64-mingw32)

    命令行选项变更#

    GCC 14: - -mtp= 支持更改 TPIDR 寄存器用于 TLS 访问 - -mearly-ra= (默认 -O2+ 启用) - -mearly-ldp-fusion / -mlate-ldp-fusion

    GCC 15: - -mbranch-protection=gcs 支持 GCS - -mcpu=native 改进对未知 heterogeneous systems 处理 - -mfix-cortex-a53-* 在不兼容架构时静默忽略 - SME 修饰符 +sme 不再隐式启用 SVE（但 GCC 尚不支持无 SVE 的 SME）

    GCC 16: - -mautovec-preference 自动向量化 ISA 选择 - -menable-sysreg-checking 系统寄存器访问检查 - SME without SVE 正式支持

    编译示例#

    # GCC 14: 编译支持 SME2 的代码
gcc -march=armv9-a+sme2 -O2 program.c

# GCC 15: 编译支持 FP8 的代码
gcc -march=armv9.5-a+fp8 -O2 program.c

# GCC 16: 编译支持 MTE stack tagging 的代码
gcc -march=armv9.6-a -fsanitize=memtag -O2 program.c

# 使用 generic 架构级别
gcc -march=generic-armv9-a -O2 program.c

# 指定 CPU 优化
gcc -mcpu=neoverse-v3 -O2 program.c

    // 检测 SME 支持
#ifdef __ARM_FEATURE_SME
  // SME 可用
#endif

// 检测 SVE2 支持
#ifdef __ARM_FEATURE_SVE2
  // SVE2 可用
#endif

// 检测 FP8 支持 (GCC 15+)
#ifdef __ARM_FEATURE_FP8
  // FP8 可用
#endif

// 检测 Function Multi Versioning (GCC 16+)
#ifdef __HAVE_FUNCTION_MULTI_VERSIONING
  // FMV 正式支持
#endif

    总结#

    GCC 14/15/16 对 ARM64 架构的支持持续增强： - CPU 支持: 从 Cortex-A520/A720/X4 到 Apple M4/M5, NVIDIA Grace, Qualcomm Oryon - 架构级别: 从 generic 到 armv9.6-a - 特性扩展: SME/SME2, FP8, SVE2.1/2.2/2.3, GCS, MTE 等大量新特性 - ACLE 支持: 持续扩展 intrinsics 和预定义宏 - 优化改进: 寄存器分配、指令融合、自动向量化等

    这些改进使得 GCC 在 ARM64 平台上具有更强的性能优化能力和更完整的架构特性支持。
