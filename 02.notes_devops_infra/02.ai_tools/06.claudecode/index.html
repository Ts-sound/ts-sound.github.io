    Claude Code#

    Claude Code 是一个运行在终端内的 AI 编程助手，支持 Linux / macOS / Windows。

    cc-switch — 桌面端管理工具，提供图形界面统一管理供应商、MCP、Skills，支持一键切换。 cc-connect — Agent 桥接工具，将本地 AI Agent 桥接到飞书、钉钉、Telegram、微信等即时通讯工具，实现远程操控。

    安装#

    前置要求#

    • Node.js >= 18
    • 使用 npm 全局安装

    安装命令#

    npm install -g @anthropic-ai/claude-code

    验证安装：

    claude --version

    配置 DeepSeek 后端#

    Claude Code 默认使用 Anthropic 的模型。要接入 DeepSeek 模型，需配置以下环境变量。

    Linux / macOS#

    export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<你的 DeepSeek API Key>
export ANTHROPIC_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash
export CLAUDE_CODE_EFFORT_LEVEL=max

    API Key 在 DeepSeek Platform 获取。

    Windows (PowerShell)#

    $env:ANTHROPIC_BASE_URL="https://api.deepseek.com/anthropic"
$env:ANTHROPIC_AUTH_TOKEN="<你的 DeepSeek API Key>"
$env:ANTHROPIC_MODEL="deepseek-v4-pro"
$env:ANTHROPIC_DEFAULT_OPUS_MODEL="deepseek-v4-pro"
$env:ANTHROPIC_DEFAULT_SONNET_MODEL="deepseek-v4-pro"
$env:ANTHROPIC_DEFAULT_HAIKU_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_SUBAGENT_MODEL="deepseek-v4-flash"
$env:CLAUDE_CODE_EFFORT_LEVEL="max"

    持久化配置#

    环境变量在终端关闭后会失效，建议写入 shell 配置文件：

    Linux / macOS 写入 ~/.bashrc 或 ~/.zshrc#

    cat >> ~/.bashrc << 'EOF'

# Claude Code with DeepSeek
export ANTHROPIC_BASE_URL=https://api.deepseek.com/anthropic
export ANTHROPIC_AUTH_TOKEN=<你的 DeepSeek API Key>
export ANTHROPIC_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_OPUS_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_SONNET_MODEL=deepseek-v4-pro
export ANTHROPIC_DEFAULT_HAIKU_MODEL=deepseek-v4-flash
export CLAUDE_CODE_SUBAGENT_MODEL=deepseek-v4-flash
export CLAUDE_CODE_EFFORT_LEVEL=max
EOF

source ~/.bashrc

    使用#

    cd /path/to/your-project
claude

    环境变量说明#

    变量 作用 推荐值
    ANTHROPIC_BASE_URL API 端点地址 https://api.deepseek.com/anthropic
    ANTHROPIC_AUTH_TOKEN API 密钥 从 DeepSeek Platform 获取
    ANTHROPIC_MODEL 默认模型 deepseek-v4-pro
    ANTHROPIC_DEFAULT_OPUS_MODEL Opus 级模型（主模型） deepseek-v4-pro
    ANTHROPIC_DEFAULT_SONNET_MODEL Sonnet 级模型 deepseek-v4-pro
    ANTHROPIC_DEFAULT_HAIKU_MODEL Haiku 级模型（轻量任务） deepseek-v4-flash
    CLAUDE_CODE_SUBAGENT_MODEL 子 Agent 模型 deepseek-v4-flash
    CLAUDE_CODE_EFFORT_LEVEL 思考力度 max

    cc-connect#

    Agent 桥接工具，将本地 Agent 桥接到飞书、钉钉、Telegram、微信等聊天平台，实现远程操控。

    • 安装：npm install -g cc-connect
    • 启动：cc-connect
    • Web 后台配置：cc-connect web → 查看 token 登录

    Web 后台配置流程#

    1. 登录：运行 cc-connect web，浏览器打开管理后台
    2. Projects → my-project（默认工程） → Settings：配置 Agent 类型（如 claudecode）、工作目录
    3. Projects → my-project → Overviews → add platform：添加聊天平台（如飞书，出现二维码，飞书客户端扫码确认）

    4. 确认 Agent 启动成功后，即可在对应平台开始对话

    5. 参考：GitHub | 中文文档

    cc-switch#

    cc-switch 是 Claude Code 的 Plugin（插件），提供桌面端图形界面来管理供应商配置、MCP、Skills 和用量统计。支持 Claude Code、Codex、Gemini CLI、OpenCode、OpenClaw 等多个 AI 编程 CLI。

    • 供应商切换：50+ 内置供应商预设，一键切换，无需手动编辑环境变量或配置文件
    • 热切换：切换供应商后 Claude Code 无需重启终端即可生效
    • 统一 MCP 管理：跨应用管理 MCP 服务器配置，支持双向同步
    • Skills 管理：从 GitHub 仓库一键安装 Skills，支持 symlink 和文件复制
    • 用量统计：跟踪 token 消耗和费用，支持自定义模型定价
    • 系统托盘：托盘菜单快速切换供应商，无需打开主界面

    官方文档：ccswitch.io

    系统要求#

    系统 最低版本 架构
    Windows Windows 10+ x64
    macOS macOS 12 (Monterey)+ Intel (x64) / Apple Silicon (arm64)
    Linux Ubuntu 22.04+ / Debian 11+ / Fedora 34+ x64 / ARM64

    前置要求#

    安装 Node.js 18 LTS 或更高版本：

    # Ubuntu/Debian
curl -fsSL https://deb.nodesource.com/setup_lts.x | sudo -E bash -
sudo apt-get install -y nodejs

# 或使用 nvm
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
nvm install --lts

    Linux 安装#

    Debian / Ubuntu（.deb）：

    # 从 Releases 页面下载对应架构的 .deb 包
sudo dpkg -i CC-Switch-v{版本号}-Linux-*.deb

# 修复依赖问题
sudo apt-get install -f

    AppImage（通用）：

    chmod +x CC-Switch-v{版本号}-Linux-*.AppImage
./CC-Switch-v{版本号}-Linux-*.AppImage

    ArchLinux（AUR）：

    paru -S cc-switch-bin
# 或
yay -S cc-switch-bin

    macOS 安装#

    brew tap farion1231/ccswitch
brew install --cask cc-switch

    Windows 安装#

    从 Releases 下载 .msi 安装包或 .zip 绿色版。

    快速使用#

    1. 添加供应商：点击「Add Provider」→ 选择预设或自定义配置
    2. 切换供应商：选择供应商 → 点击「Enable」
    3. 命令行工具需要先通过 npm 安装：
    npm install -g @anthropic-ai/claude-code
