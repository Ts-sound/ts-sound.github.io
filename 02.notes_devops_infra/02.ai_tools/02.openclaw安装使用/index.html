    OpenClaw 安装与使用指南#

    简介#

    OpenClaw 是一个运行在本地环境的高权限 AI 智能体，具有以下核心特性：

    特性 说明
    本地部署 运行在你的服务器或电脑上，数据完全自主可控
    多平台支持 支持飞书、WhatsApp、Telegram、Discord、Slack 等主流聊天工具
    浏览器控制 可以浏览网页、填写表单、提取数据
    系统访问 读写文件、执行 Shell 命令、运行脚本
    持久化记忆 记住你的偏好和上下文，成为真正属于你的 AI
    插件扩展 支持社区技能插件，甚至可以自己编写插件

    ⚠️ 安全提示：由于 OpenClaw 运行时权限较大，出于安全考虑： - 不建议在本地或工作机上直接安装 - 建议使用 Docker 容器化安装 - 或直接使用云服务器（如腾讯云/阿里云 ECS）安装

    安装方法#

    方法一：Docker 安装（推荐）#

    详细步骤请参考 官方 Docker 安装文档。

    方法二：二进制安装#

    curl -fsSL https://openclaw.ai/install.sh | bash

# 验证安装
openclaw --version

    📌 注意：在 Ubuntu 22.04 上安装成功，其他系统可能出现兼容性问题，建议优先使用 Docker 方式。

    更多安装方式请参考 官方安装文档。

    快速开始#

    1. 初始化配置#

    # 运行初始化向导
openclaw onboard

    初始化过程中需要配置以下内容：

    配置项 说明
    Models 选择 AI 模型提供商（如 OpenAI、Anthropic、NVIDIA 等）
    Channels 配置通信渠道（飞书、Telegram、Discord 等）
    Skills 选择技能插件（浏览器操作、文件处理等）

    💡 提示：可以先跳过配置，后续通过 Dashboard 或命令行进行配置。

    2. 访问 Dashboard#

    # 启动 Gateway 服务
openclaw gateway

    远程访问方式（容器环境）：

    # 1. 确保容器已启动 SSH 服务
# 2. 建立 SSH 隧道
ssh -N -L 18789:127.0.0.1:18789 user@<host>

# 3. 浏览器访问
# 本地：http://localhost:18789/
# 带 Token：http://localhost:18789/?token=YOUR_TOKEN

    3. 批准设备接入#

    首次在新设备上访问 Dashboard 时，需要手动批准：

    # 查看待批准的设备请求
openclaw devices list

# 批准设备接入
openclaw devices approve <request_id>

    常见问题#

    1. 安装失败#

    问题：在 Ubuntu 22.04 上安装成功，其他系统下出现安装失败

    解决方案：

    • 使用 Docker 安装（推荐）
    • 检查系统依赖是否完整
    • 确保网络连接正常

    2. 连接问题#

    问题：disconnected (1008): pairing required

    解决方案：

    # 查看设备列表
openclaw devices list

# 批准请求
openclaw devices approve <request_id>

    4. 模型配置问题#

    问题：模型无法加载或 API 调用失败

    解决方案：

    • 不同厂家配置方法不同，参考官方文档
    • 验证 API 密钥是否正确
    • 检查网络连接
    • 确认模型是否支持

    model providers

    最佳实践#

    1. 生产环境部署#

    docker 容器化部署

    2. 监控和日志#

    # 查看实时日志
docker logs -f openclaw

# 配置日志轮转
openclaw config set logging.rotation.maxSize "100m"
openclaw config set logging.rotation.maxFiles "5"

    3. 备份和恢复#

    # 备份配置
tar -czf openclaw_backup_$(date +%Y%m%d).tar.gz /root/.openclaw

# 恢复配置
tar -xzf openclaw_backup_YYYYMMDD.tar.gz -C /

    使用技巧#

    指定agent进行对话：openclaw agent --agent local --message "see the config chages "
