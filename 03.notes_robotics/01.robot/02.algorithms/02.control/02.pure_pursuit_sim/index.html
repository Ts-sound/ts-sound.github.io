def compute_tracking_error(traj, path):
    """Compute average minimum distance from trajectory to path"""
    errors = []
    for point in traj:
        dists = np.hypot(path[:, 0] - point[0], path[:, 1] - point[1])
        errors.append(np.min(dists))
    return np.mean(errors), np.max(errors)

    4. Analysis and Conclusion¶

    现象总结¶

    1. 圆形轨迹：纯追踪算法跟踪圆形轨迹效果良好，稳态误差由前视距离$L$决定。
    2. 8字形轨迹
      • 前视距离$L$较小时：响应速度快，但易出现轨迹抖动、路线偏移问题。
      • 前视距离$L$较大时：轨迹更平滑，但滞后现象加剧，弯道处误差增大。
    3. 参数特性：前视距离$L$存在最优取值，取值过大或过小都会导致误差上升。

    局限性¶

    • 纯追踪属于几何算法，未考虑车辆动力学特性。
    • 高速行驶时需增大前视距离，否则系统会失稳。
    • 无法避让动态障碍物。
    • 在曲率突变的轨迹上表现较差。
